# 正式源码对应

- contact-analysis.mjs：米制源脚轨迹的地面/接触/稳定落脚估计。事件包含确认延迟，非人工标注或力学承重。
- beat-steps.mjs：选三个首尾接触脚一致的两拍交替步；一落脚一拍是本轮假设。分段时间映射在整数拍采样落脚锚点；不再以参考100 BPM缩放整段。
- vrm-dance.mjs：现有音频时钟，可靠起音网格以有限速度修正相位。epoch隔离换流；不识别强拍/小节。
- local-dance.mjs、vrm-retarget.mjs：本机VRM预采样，保留相对双脚的髋部平衡位移，移除源长距离场景移动。
- contact-plant.mjs：世界空间脚踝锚定与有限髋下沉；输出成功/跳过/拒绝/残差。非完整身体物理。
- BeatStudy.vue：只读研究诊断；Electron白名单拣选有限字段，拒绝任意payload。

没有支撑兼容的后继时继续当前短句，记录blockedTransitions；混合在最后0.3拍提前准备。源帧采样误差不包含混合/限速后的视觉延迟。真实源动作、角色模型及派生姿态不随项目分发。
