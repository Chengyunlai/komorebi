# 核心实现和验收范围

- src/motion/sequence-assessment.mjs：流式聚合局部骨骼与根运动、约束前/最终残差；保留统计和有限时间候选，不存原始pose。角速率由最短四元数弧长得到，q/-q等价；angularSpeedChange是角速率标量之差，不是角加速度向量。根加速度使用局部位移速度向量差。
- src/motion/segment-assessment.mjs：同源时间三条件、固定步长、协作取消与进度；输出source实际采样区间，不假装等于歌曲乐句。结束恢复UI职责在ReplayStudy。
- src/motion/replay-experiment.mjs：新增最终层方向/旋转残差，防止用约束前的近零映射残差掩盖约束后改写。
- src/motion-lab/bvh.mjs：固定源时刻roundtrip容差1e-8帧，修复浮点时间乘除导致的上一帧误读。本机1901帧原30处错索引，修后0；四种帧时长×1901帧单测覆盖。

阈值默认12rad/s、角速率变化80rad/s²、根约束改写4cm，仅用于定位候选。阈值需要根据素材、身体能力和目标风格再评估，不能把超阈值等同动作错误。采样缺口会断开速度窗口；候选数量有上限，最坏全局统计不受候选截断影响。

原生连续图像序列与UI数值来自不同采样起点：视频含名义9秒的源第270帧，UI严格向上对齐9秒后从第271帧开始。报告分别记录真实采样时间；不把捕获器滞后一帧或range毫秒量化当作模型失效。
