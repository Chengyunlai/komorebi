# 日常音乐执行

运行 `node examples/stage-23-daily-execution/user_code/main.mjs`，用原创PCM实际分析、实际VRMDanceController、实际本地动作准备与执行器驱动合成目标，检查激活、静音与足目标报告。无需商业模型或网络。

原生验证：动作研究 → 音乐执行 · 集成 → 运行音乐执行验证。角色加载完成后运行27秒（24秒原创音频PCM和3秒零输入），不外放。它使用实际Character组件，供检查最终写入者和旧约束是否被调用，不代表听感同步已经验收。
