# 音乐信号基准（MUSIC-01）

用**已知真值的合成鼓点**给宿主音乐分析打分：BPM 误差、起音召回、半/倍速陷阱、段落动态、静音断流恢复、端到端"特征→舞句规划"。不包含任何商业音频；不读取用户音乐库。

从项目根目录运行：

```sh
node examples/stage-33-music-baseline/user_code/main.mjs
```

输出 `music-baseline/v1` JSON：每组输入的起音匹配、BPM 误差、半/倍速比例、状态流转，以及端到端规划摘要（检测 BPM → 舞句计划）。

当前基准结果（本机，48kHz 单声道）：

| 输入 | 起音 | BPM | 半/倍速 | 首次 tracking | 终态 |
| --- | --- | --- | --- | --- | --- |
| 稳定 90 | 24/24 | 89.6（误差 0.5%） | 0 / 0 | 2.01s | tracking |
| 稳定 120 | 32/32 | 120.0（0%） | 0 / 0 | 1.51s | tracking |
| 稳定 150 | 40/40 | 150.0（0%） | 0 / 0 | 1.21s | tracking |

| 纯静音 | — | 无 | — | — | silent |

限制：合成鼓点比真实歌曲干净（无混响、人声、弱拍摇摆），结果不代表真实歌曲准确率；半/倍速陷阱仅覆盖一种节奏型；端到端仅验证布线，不评价舞蹈。**真实歌曲对照需要你提供本机音乐文件路径**（做完即删，不入库、不上传）。
