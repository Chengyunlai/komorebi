# 全身片段与支撑脚

先运行 `node examples/stage-07-fullbody-clips/user_code/main.mjs`，再读 [core](core/README.md)。

日常音频动作使用五类原创片段：侧踏点步、交叉收臂展开、斜向伸展、提膝对侧摆臂、下沉重音。每段有准备/主动作/跟随/收势，左右交替；根据音频频段与能量选择，避免连续重复，不把每个起音当成动作重启。

角色照常从桌面打开，音乐入口支持真实音频和原创24秒音频。短鼓间隙允许完成片段；明确静音、停止、断流与禁用舞动收势。

支撑脚用解析双骨IK尽量留在目标，摆动脚按作者定义的弧线移动；它不是完整地面接触或碰撞系统。纯模拟测试及实际音频诊断不等于审美验收。
