# 连续舞句变化

先运行 `node examples/stage-09-phrase-variety/user_code/main.mjs`，再读 [core](core/README.md)。

六类原创八拍主题：侧踏摆臂、宽步绕臂、前点胸腰、提膝对摆、斜踏伸展、后点低律动。主题改变足部前后/斜向路径、摆动高度、重心与上身配合，不只改手臂。

内部八拍边界才能换主题。能量/频段经1.2秒平滑后参与选择，风格与近期主题/使用次数共同评分，稳定歌曲也能逐渐出现不同主题；不声明识别了真实音乐小节或副歌。

界面入口保持轻量。启动并完成角色加载后，开发复测可用 `open -n release/Komorebi.app --args --music-demo` 或 `--music-audio`。

本页为阶段09历史行为；当前编排见stage-11，稳定音乐不再强求遍历全部六类主题。
