# 候选后继与拒绝原因

运行 `node examples/stage-20-successor-assessment/user_code/main.mjs`，使用原创合成源；或传本机BVH路径和明确的米/源单位尺度：

```
node examples/stage-20-successor-assessment/user_code/main.mjs /absolute/reference.bvh 0.01
```

研究窗口“材料 · 连续过渡”显示当前候选判断，点击“检索候选后继”查看前五项。待接触复核的候选只能手动研究预览；当前未将它们自动用于日常舞蹈。
