# VRM桌宠与音频动作

先运行 `node examples/stage-06-vrm-desktop/user_code/main.mjs`，再读 [core](core/README.md)。
日常透明桌宠已换为本机VRM。首次使用在配置与管理 → 偏好设置 → 桌面角色导入合法取得的.vrm。当前用户模型是Jessair Cute Model，不随app和源码提供。
右键角色 → 音乐 · 网易云 → 真实音频跟拍，或原创节奏试跳。静音、断流、停止、关闭舞动和减少动态效果时收势。无音频行为预览仍通过原有界面明确标记。
单击打开轻气泡，按住拖动，歌词继续显示。音频仅本机分析，音乐信号项目保持独立。此版本不包含BVH参考回放和商用动作素材。
