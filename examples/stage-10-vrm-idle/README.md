# 日和m05到VRM默认待机

先运行 `node examples/stage-10-vrm-idle/user_code/main.mjs`，再读 [core](core/README.md)。

截图所选hiyori_m05是当前VRM默认待机来源。保留转头、身体倾斜、轻微手臂、呼吸、眨眼和视线；脚仍由IK约束，动作幅度适配三维角色。

音乐/明确舞动预览优先，收势后恢复待机；系统减少动态效果下关闭待机位移。语音口型保持由实际播放音频控制。
