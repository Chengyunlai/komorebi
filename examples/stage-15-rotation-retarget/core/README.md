# 数学、假设与正式源码

正式实现src/motion-lab/rotation-retarget.mjs。源世界旋转S(t)由BVH世界矩阵提取；C使用既有身体参考旋转，B(0)取原方向映射在首帧的目标世界姿态：

`T(t) = C * S(t) * inverse(S(0)) * inverse(C) * B(0)`

把目标世界旋转左乘实际父骨世界旋转的逆得到局部四元数，并按父到子写入。sourcezero不是已验证的T pose；sourcefirst也不是bind pose。B(0)校准约定保留目标选择的初始扭转分支，无法恢复源首帧未知的绝对解剖扭转。

单个骨段方向只约束两个旋转自由度。纯轴向旋转可以不改变骨与直接子端点，却改变袖子/手掌朝向及非共线后代。本阶段fixture添加侧向后代，防止只画共线骨架掩盖差异。

源动作若有改变子骨局部方向的position通道，源旋转与端点方向可能不能同时满足。研究UI同时保留方向误差和旋转残差，不能用完整旋转残差近零掩盖该冲突。源/目标坐标须无反射，退化骨架和首帧质量仍影响校准。

朝向残差比较实际normalized世界旋转与声明参考，twist分量将相对四元数向量部投影到目标骨局部子骨方向后取绝对主值；无轴或投影四元数范数接近0时未定义。它是参考残差，不是力学扭矩、实际肌肉扭转或舞蹈表达评分。

核心另见replay-experiment.mjs的retargetMode/trace.sourceMapping、ReplayStudy.vue模式对照。根平移仍独立使用stage14的Y-up水平旋转策略。
