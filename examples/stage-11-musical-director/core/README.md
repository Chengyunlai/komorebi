# 核心路径

- musical-director.mjs：短/长能量、起音密度、带迟滞的quiet/flow/drive/rising/settling响应；内部主题→呼应→对比→回归，不是歌曲段落识别。
- vrm-dance.mjs：在内部八拍边界选择兼容主题，短置信度空窗保留最近可信拍速，处理半/倍拍候选，起音只做有限相位校正。
- vrm-phrases.mjs：呼应变化在接缝值/导数为零；短起音增加肘臂表达，承重脚不跟着音量或起音偏移。
- vrm-idle.mjs：只要舞句活跃，即使力度低也不由待机抢占；静音收势后恢复默认待机。

音乐信号分析仍在独立项目。本阶段只改变消费信号的桌宠动作与编排层。
