# 共享采样与归因

`createMaterialSequence`提供研究预览和完整窗口诊断的同一采样逻辑，入段固定对齐贯穿整个后续；混合期间接触未知，禁止沿用出段plant。

`createFootWindowAssessment`只收聚合指标；源的各脚增量按水平朝向及腿长尺度换算到目标米制坐标，目标从相同窗口的自身起点计算增量。差值表示该近似映射下的运动不一致，不是脚底接触误差。

断点：尺度为adapter.scale / metresPerSourceUnit，yaw为源初始左右髋轴到目标初始左右髋轴，源/目标锚点分别固定。未来要引入足底/承重，需要额外几何或标注，不能以低踝直接代替。
