# 验证证据 / Evidence

历史实现记录中提到的截图、歌曲分析、动作标注、视频与派生动作均为本机研究产物，不随开源快照提供。文档中的路径说明当时的验证方法，不代表仓库内附有素材，也不能代替复现实验。

可公开复现的基准使用源码中的合成信号与骨架夹具：先运行 `node examples/stage-33-music-baseline/user_code/main.mjs`，再运行 `npm test`。需要 VRM/BVH 的研究，请自行取得合适许可后在本机导入。勿将个人资料、录音、第三方角色或模型权重提交到此目录。

Historical captures, song analysis, motion annotations and derived motion remain local. Reproducible synthetic fixtures live in examples and tests; licensed research assets must be supplied separately.
