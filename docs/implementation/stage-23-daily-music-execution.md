# Stage23 日常音乐身体执行整合

## 1 本轮做什么

把stage22的Y-up、完整旋转和源踝目标用于本地音乐动作预采样。桌宠采用显式in-place-feet-midpoint根策略：水平移除源双踝中心的场景旅行，保留相对步态与高度；这不是固定地面上的真实接触。源髋关节中心以相同策略适配。

姿态、根与已执行的世界米制踝目标一起进入动作库，并在插值/片段混合中一起传播。Character先混合局部姿态与根，再按同权重混合目标踝，由末端执行器写最终腿姿态；原source contact plant不再覆盖本地动作，程序原创舞句的footPlant保留。估计接触仅用于旧时钟/选段诊断，不生成硬锁。

保留当前三段两拍选择及内部音乐拍映射，不声称本轮已解决舞蹈知识/编排。新增研究入口“音乐执行 · 集成”，直接渲染实际Character，输入实际MusicAnalyzer对原创PCM的输出，无硬编码beat注入、无外放、无正式主进程或用户设置修改。

Example：`examples/stage-23-daily-execution/user_code/main.mjs`；断点：原始PCM feature、music clock、localPose.feet、执行器期望残差及finalWriter。测试：脚目标随混合传播、权重淡入淡出、不旧锁脚、准备/取消还原；原生真实VRM27秒90/120/140节奏与14–16秒静音、24秒后静音/停止观察。

## 4 后续评估

### 基础与原生端到端验证

159/159测试通过，构建通过。合成示例复用实际MusicAnalyzer/demoBlock、VRMDanceController、动作库与执行器，675份特征、静音末段权重均0，目标误差约数值零；合成源没有可靠落脚事件，明确走2片段fallback库，不能代替真实源三片段验证。

原生真实角色可见窗口运行27秒+4秒淡出观察，151次visibility采样均visible；675features，3个实际bank片段0/1/2均被播放、切换19次，59份Character报告/45份active报告。所有active finalWriter为source-trajectory-executor，legacyContactApplied违规0，renderer errors为空。无外放/无正式主进程数据修改。

BPM估计约89.55、120、139.53，对应原创90/120/140分段；120段有明显估计追赶（约13.7秒才达到120），不伪造即时真值，也不当作已解决听感同步。14–16秒静音：weight 1@14.087 → 0.1409@14.611 → 0@15.121；24秒后零输入：0.6903@24.433 → 0@24.966，27秒后waiting/off/weight0。

最坏0.5秒采样报告目标残差0.035043985m@13.712秒/clip0/一脚投影，最大采样局部旋转改写1.183805rad（约67.83°）@3.224秒/weight1/clip1/switch1；该角度峰值目标误差近零、投影0，不能简单等同不可达，也不能宣称这是逐帧上界。实时连续观察另记录。

### 剩余执行一致性缺口

代码审查确认BeatStepPlayer最后对各骨旋转按9rad/s、根按0.6m/s独立限速，脚目标未随之同相位过滤；MotionBankPlayer也有相同结构（7rad/s、0.4m/s）。因此最终旋转/根与目标踝不再来自同一运动样本，执行器会再次改写腿部。此是已证代码不一致，但尚未单独复测归因67.83°峰值。

下一轮按同模型/同输入拆开sample、preblend和limiter三个阶段测FK踝位差与改写，再比较统一插值因子作用于姿态/根/踝的策略。先定位该层，不凭空增加膝轨迹或更强锁脚。三段编排和静态入段首帧混合仍保留为后续控制器问题。

### 连续呈现与更新生效核对

第二轮可见窗口实际运行再记录273张本webContents呈现帧，平均间隔约114ms（约8.77fps），最大180ms，128次visibility记录hidden=0。按实际墙钟时间戳生成31.029秒VFR视频，逐帧PTS误差<4e-15秒；容器nominal r_frame_rate=30不代表捕获率。全273帧及峰值邻域放大检查未辨认明显膝翻折或画幅裁切，快速侧/背/正转向和抬膝回收仍存在；约9fps及遮挡不能排除瞬时/细小抖动。

第二轮0.5秒报告采样最大改写1.10872rad（约63.52°）@13.597秒/weight1/clip1，左小腿1.10872、左脚0.86247、左大腿0.25244rad，目标残差近零、投影0。与首轮67.83°不同采样相位，不能称同一瞬间复现或逐帧上界。原生证据`docs/evidence/daily-music-native.json`保留两轮原始指标及呈现时间戳，无骨姿态轨迹导出。
