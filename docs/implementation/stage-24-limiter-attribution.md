# Stage24 混合与限速分层归因

## 1 本轮做什么

stage23实际日常链路中出现3.5厘米采样目标残差和较大腿改写。本轮在相同模型、相同原创PCM/音乐时钟/选段上，分别评估源采样、预混合、旧独立限速、下身一致限速。源/目标资产只在内存中使用；输出FK踝目标差、求解后残差、局部旋转改写、相对当前预混合目标的踝滞后，不导出姿态。

候选一致策略：hips+下身关节+根+踝目标共享一个插值因子，上身局部关节仍独立限制，防止腕部高频动作拖慢步态。该策略只在证据证明收益且滞后可接受后应用，旧默认先保留。跟踪时钟和选段必须相同，否则不能归因。

Example `examples/stage-24-limiter-attribution/user_code/main.mjs`；断点：sample/blended/limited、共享因子、FK踝差与求解改写、coherent目标位移滞后。验收：旧行为等价、目标/根/下身同因子、上身独立、无突变输入修改、实际VRM确定性回放和恢复。不能用减慢/冻结动作制造低误差。

## 2 结果与验证

实施后补实际证据，明确各层贡献和候选策略取舍。

## 3 资源和调整

复用实际VRM、源BVH和既有MusicAnalyzer/demoBlock。无需新增模型或训练资源。不增加接触锁定、测力或脚底真值。

## 4 后续评估

若预混合主导，则进入双侧运动窗口过渡；若限速主导，统一过滤后仍需检查听感相位和动作动态。三段两拍编排不是最终舞蹈控制器。

### 实模分层结果与未采用的候选

177/177测试通过，构建通过。实际模型固定27秒PCM、675features、656满权重样本，三播放器时钟/片段相同。注意rawSample指已经经过身体适配和in-place根策略的目标动作库采样，不是原始BVH；该层根速度不能直接称为原舞者速度。

原静态过渡各层：FK踝目标差max/P95，rawSample约0.0361/0.0121m；preBlend 0.2629/0.0490m；legacyLimited 0.8820/0.3246m。旧限速最终求解残差max0.04728m，旋转改写max1.25545rad，证明该层扩大了几何不一致。

coherent-lower-body消除了本次投影残差，但目标滞后max0.41314m、P95 0.25066m、mean0.09479m，共享因子mean约0.446。不能以明显延迟脚目标换取“低误差”，未采用。

planned-lower-body保留计划根/下身/目标踝，只限上身；目标滞后0，求解残差数值零，改写max降至0.53374rad。但静态预混合下最终下身角速度峰值81.283rad/s，高于旧限速40.678rad/s，未直接采用。实际执行速度按相邻满权重帧计算，跨静音/权重缺口不连接，共654连续样本。

### 朝向与运动预备段

新增独立heading-preroll研究过渡：按世界Y旋转入段，根与踝目标同变换，围绕固定rest枢轴旋转，不累加场景平移；入段从落脚前的真实运动预备段前进到原始start，落脚锚点仍在片段边界0拍，不提前消耗入段第一拍。根据前一个反侧可见落脚间隔估计预备时标，不足则显式回退首步间隔；一落脚对应一拍仍是现有时钟假设，不是原曲强拍识别。所有入段后续姿态持续使用该朝向，避免边界重置。旧static默认保持。

在同一source-plan fingerprint=3020268532上，对heading-preroll预备段时长做有限对照：

| 过渡拍长 | 最终根速度max/P95 m/s | 最终下身角速度max/P95 rad/s |
| --- | --- | --- |
| 0.3 | 5.421 / 2.293 | 22.089 / 15.625 |
| 0.6 | 3.735 / 2.051 | 22.708 / 16.068 |
| 1 | 3.669 / 1.956 | 25.908 / 15.956 |

这些planned条件目标滞后均0、求解残差约数值零；更完整的准备段消除了该短过渡造成的根速度峰值，但剩余大根速度出现在非过渡部分，不能继续靠调blend时长解释。原legacy根速度受逐轴0.6m/s限制，世界合速度max约1.039m/s。新候选虽然角速度峰值减小，仍改变根动态；日常默认不切换，下一步比较原BVH全局根、当前去双踝中心的呈现策略及身体适配后的根，定位是否去旅行策略带入高频分量。

证据：`limiter-attribution-four-stage-native.json`、`limiter-attribution-native.json`、`preroll-limiter-native.json`、`transition-window-native.json`。实际研究页读取当前Character/本地模型，两次原四阶段JSON完全一致；后续五阶段与时长矩阵明确标注各自次数，不混称重复验证。所有调用恢复elapsed0/features0/按钮可用，renderer/UI errors为空，无源骨姿态导出。

### 实时候选预览验证

研究页新增本页限速策略选择，支持使用实际 Character 实时运行 planned-lower-body + heading-preroll + 1拍候选，未修改日常桌宠默认。177项测试和生产构建通过。

隔离Electron窗口实际播放27秒原创PCM、观察至31秒：675个features，报告确认为planned-lower-body与heading-preroll，无隐藏样本和renderer errors。24.041秒权重1，24.576秒0.281，25.093秒归零/off；27秒后waiting，按钮恢复。抽样最大求解残差约5.89e-16米、旋转改写0.5135弧度、projection0、旧接触锁冲突0。该结果只证明候选真实执行与静音恢复，不证明视觉自然、脚底接触或音乐同步质量。

无需新增资源；后续优先分离原BVH根轨迹与去双踝中心的呈现策略，检查根运动速度来源，再做完整动作观感对照。用户要求后续每轮均按“本次做什么 / 结果、验证与结论 / 资源和调整 / 进一步评估与下一步”汇报。
