# Stage22 源踝轨迹跟随

## 1 本轮做什么

stage21已发现源踝近静止而目标移动10–19厘米。本轮用源动作的踝部位移作为目标身体末端轨迹：从源首帧与对应目标标定帧的两侧独立锚点做水平朝向/腿长尺度换算，旋转映射后用双骨腿求解跟随轨迹。滑步与提脚仍保留，不推断plant，不按接触规则降髋。

研究页关闭/开启对照，完整窗口记录真实目标误差、不可达投影和腿部旋转改写。公开example `examples/stage-22-ankle-tracking/user_code/main.mjs`；断点：源/目标锚点、期望目标、腿长可达域、源膝方向、投影误差与旋转改写。验收：可达/不可达、保留足部世界朝向、父节点变换、确定性seek、坏输入不部分改写；真实VRM完整4秒对照。

## 2 结果与验证

实施后补实际数值和画面证据。不把不可达目标投影后的零误差假称原目标达成。

## 3 资源和调整

无需新增模型，不依赖未知脚底偏移；目标是骨踝轨迹，不是足底物理接触。当前研究角色和BVH仍仅本地使用。

## 4 进一步评估

身体旋转保真与末端位置保真存在取舍，需报告改写量和可达性，观察膝部反折、过伸、抖动；足接触/承重与音乐控制仍独立验证。

### 首轮发现与锚点修正

最初用窗口9秒的目标踝作为锚点，真实模型只部分改善：左/右最大增量差20.56/31.05厘米降至11.31/23.30厘米；241采样两脚合计190次带余量可达域投影，最大原目标残差23.30厘米、最大局部骨旋转改写79.38°。右脚一个短incoming估计plant窗口的路径还略有增加，因此未把该版本当成功结果。

分析：窗口开始的旋转映射本身已有端点偏差，重建锚点会把这个偏差带入整个期望轨迹。改用适配器相同的源原始首帧0与对应目标标定帧0，固定锚点贯穿所有源窗口；镜头仍以预览起点9秒的髋位置固定，不因标定改变观察位置。旧窗口锚点数据仅作中间方案证据，最终结论以修正后原生结果为准。

### 已执行基础验证

151/151测试通过；合成不同腿段比例目标的原旋转基线踝增量差约2.79厘米，跟随后约数值零，无投影，最大局部旋转改写约4.57°。这是可达合成场景，不能外推真实模型。模块提供每脚reachMargin/geometricReachable，投影次数是带安全余量域的计数，不等于相同数量帧或解剖绝对不可达次数；非均匀父缩放不在本轮支持范围。

### 对锚点假设的复测

改用源0首帧后，真实最大原目标残差仍约23.36厘米、190次投影，窗口增量差也基本不变。该结果否定“窗口锚点是主要原因”的假设；首帧锚点作为稳定标定策略保留，但不将其称为解决办法。

接着加入骨盆参考点适配：源左右UpperLeg起点中点作为髋关节中心轨迹，按相同yaw/尺度映射到目标左右UpperLeg中心。通过目标hips在父坐标中的平移对齐中心，再执行双腿IK；保留hips旋转。这处理不同骨架hips参考点/髋关节偏移，而不是依据未知接触降髋。根平移的实验上限0.3米，达到上限必须记录，不能隐瞒；未证明该阈值具有普适性。最终取舍以新增原生对照为准。

### 对髋关节中心假设的复测与坐标契约

原生模型源pelvis→socket长度0.021925m，映射到目标尺度0.024873m，目标0.040205m；差约1.5厘米。适配中心最多移动1.754厘米、无截断，但最大踝原目标残差仍23.38厘米、投影190次。说明该参考点差异真实存在，却不是本窗口大残差的主要原因。保留该层明确报告，不把它称为修复成功。

代码检查与原生映射元数据指出：旧旋转/方向映射的world conversion来自目标身体基×源初始身体基逆，包含明显pitch；根轨迹和踝目标却只用水平yaw保持Y-up。对齐身体首帧姿势与转换世界坐标系是不同职责，不能将身体基倾斜隐式当作世界重力变换。

新增独立worldAlignment选项：body-basis保持原基线，y-up只用水平朝向转换，首帧身体姿态由几何方向校准表达。UI将其与轨迹跟随开关分开，原生比较body-basis/off、y-up/off、y-up/on三条件，避免将坐标修正效果归给IK。缺少新对照证据前不认定此处已解决。

### 世界坐标对照的基础检查

156/156测试通过。新增lean-source测试确认旧body-basis转换会倾斜global Y，y-up转换保持Y并保留首帧实际身体倾斜；按时间/按采样帧路径一致，纯竖直源移动不会产生XZ漂移。旧默认行为不变，新增选项为研究对照。

位置和旋转映射的世界轴选择必须统一；身体首帧lean属于姿态，不应未经声明转成世界重力方向。UI将身体世界对齐与源踝跟随分开，脚部聚合记录两者取值及首帧腿向量的角度/长度差，便于区分坐标校正和末端求解的贡献。

### 最终原生三条件结果

同一真实VRM、9→48秒候选、固定18°机位、planar对齐；每条件完整4秒/60Hz共241采样。原body-basis/off首帧腿向量角差约0.392/0.396rad、向量差0.348/0.345m；y-up/off降为约0.00585/0.00868rad、0.00523/0.00762m，直接验证了世界坐标基不一致引入的大初始腿方向偏置。

| 条件 | 左踝最大增量差 | 右踝最大增量差 |
| --- | --- | --- |
| 原身体基 / 无跟随 | 0.205557m | 0.310462m |
| Y-up / 无跟随 | 0.021448m | 0.021145m |
| Y-up / 轨迹与髋中心适配 | 约8e-16m | 0.00365562m |

最终开启条件原目标最大残差0.00365562m；241采样×两脚累计49次带余量域投影，非49个独立帧；最大局部骨旋转改写0.145603rad（约8.34°），最大髋中心适配根平移0.0168146m，无0.3m上限截断。缺少脚底/测力与标注，不能从毫米级踝误差宣称接触物理通过。

三条件评估均恢复原1.2秒显示时间、控件和canvas hash，开启条件重复聚合完全一致，无renderer/UI错误。新录Y-up关闭/开启各121帧@30fps，完整242帧审查未辨认明显膝反折、突发过伸或画幅裁切，仍保留抬腿/转身/宽站姿；该机位遮挡及细微抖动仍限制观感判断。原body-basis/off沿用同机位旧录像，聚合数值精确复核未变化。

最终证据`docs/evidence/ankle-tracking-native.json`含三条件和中间失败假设分层；本地视频留work，不分发研究派生素材。源码不改旧默认worldAlignment，研究页明确切换Y-up和轨迹跟随。日常音乐播放器尚未切换。

最终合成example已增加pelvis参考偏移和髋旋转，原基线约4.09厘米增量差，跟随后数值零，无投影，最大局部改写约5.90°、根适配约2.09厘米。与前述早期仅腿段比例案例区分，不混作相同输入。

结论：本轮主要收益来自统一世界重力坐标，末端求解补偿剩余身体比例差；不能将全部改善归给更强IK。下一轮进入日常音乐链路，先统一坐标并检查旧足约束是否再次覆盖已验证的轨迹，再进行音频→计划→身体的端到端回归。当前目录无Git基线，未创建commit。
