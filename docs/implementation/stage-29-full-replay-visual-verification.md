# Stage29 日常执行管线 × 完整回放视觉验证（DANCE-01 补充 / BODY-01 前置）

## 本次做什么

DANCE-01 的延伸验证：此前人工确认的完整回放基于研究窗口的几何重定向（stage-05 管线）；本次验证**日常桌宠实际使用的身体执行管线**（stage-23：Y-up 完整旋转、in-place-feet-midpoint 根策略、源踝目标、末端执行器）在**完整 63 秒源舞段**上的表现。

实现：`prepareLocalDance(..., {full:true})` 新增完整回放模式——编译全部源帧（950 帧 @15Hz）后由 `createFullSegmentPlayer` **顺序播放、不切片、不选段、不重叠过渡**，淡入 0.5s / 淡出 0.5s；`Character.vue` 新增 `fullReplay` prop 与 `configureFullReplay()`；研究窗口「音乐执行 · 集成」页新增「完整回放 · 全段舞步」按钮。验证视频用 Electron 离屏渲染生成（Cute Model + 同一执行管线，逐帧 15fps → ffmpeg 合成）。

## 结果、验证与结论

**人工可看的证据**：docs/evidence/full-replay.mp4（本机研究产物：`../evidence/full-replay.mp4`）（63 秒，15fps，720×480）。

**抽帧检查（全部通过）**：
- 全段 1 秒/帧总览：动作持续变化、造型多样（跨步、侧踢、高踢腿、转身、摆臂），无扭曲变形；
- 连续序列 10fps × 5 段（0s 入场 / 20s / 30s / 45s 高踢 / 58s 收势）：帧间过渡平滑、无跳变；45–48s 为连贯高侧踢（数值上的"最剧烈"来自动作本身）；
- 脚部特写序列：跨步移动正常、鞋朝向自然、无下坠悬空。

**客观检查**：949 帧间差分（tblend difference + signalstats）分布平滑（p50 3.36、p95 8.50、p99 10.64、max 13.56），**无任何帧超过 2×p99**，无高频抖动或瞬移尖峰；最大差异出现在 46.7s 高踢腿（与 stage-28 数值最剧烈点一致）。

**数值侧对比**（stage-28 已记录）：完整回放覆盖 100% 编译帧（950 帧、零切换）；当前日常切片只覆盖 7.4%（70 帧、3 个两拍片段）。

**结论**：日常身体执行层可完整承载源舞段，观感合格。当前观感差距的**编排层归属**（stage-28）得到确认：把日常从 3 片段切片切换到完整回放/完整舞句即可显著改善。**BODY-01 的"日常执行 × 完整舞段"前置验证完成。**

**已知小瑕疵**：入场从 rest（T-pose）淡入约 0.5s，手臂有"先平举再放下"的过渡感；离屏渲染无地面参考，脚部穿地/滑步未严格判定；视频 15fps，日常 30fps 插值更顺。
