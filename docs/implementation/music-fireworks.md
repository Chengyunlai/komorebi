# 音乐烟花

日期：2026-11-03。目标：在桌宠旁增加随音乐出现、稀疏且纯装饰的烟花，验收归属 M3 日常音乐陪伴。

## 当前：姿态门控与录制优化（2026-11-03）

当前要求明确抬手/伸展，生命周期1.15秒、最多46px、24–32条亮尾与短促星芒，柔光缓存代替逐颗粒shadowBlur；稀疏预算保持。254测试/构建通过，原生窗口新录像捕获缺口已消除，见[优化与新录像](fireworks-capture-optimization.md)。

## 首版：音乐重音与手部位置（2026-11-03）

用户选择“音乐重音触发，烟花从手边绽放”。当前调用路径：`App.vue` 持有 Character 引用，将只读 `readAnchors` 回调传给 MusicFireworks；回调调用 Character 的 `getEffectAnchors()`，返回 `{at,hands:[{side,x,y}],head,chest}`。`at` 为 renderer performance 秒，位置为 CSS viewport 像素；未就绪/已卸载返回 null。新增 `src/effects/character-anchors.mjs` 从最终 raw 骨架的世界位置经过当前相机投影，包含人物容器偏移；不修改骨骼、音乐或舞蹈状态。

烟花层按自身 DOM 边界换算归一化坐标，按向外伸展、抬高手势和短时速度选手。拒绝屏幕外、过期及靠近面部的位置；缺少合适手部时跳过，不再回退到随机位置。爆发以触发时的手部位置为原点，之后粒子独立扩散，不黏住移动的手。粒子半径缩小至最多40 CSS像素，特效层改在人物前方，pointer-events:none 保持不变。

音乐选择增加近6秒衰减的起音峰值对照，压制较强起音之间的弱填充；用4秒能量均值识别当前能量抬升。低能量段间隔进一步延长（2.2–4.15秒）。手部运动仅帮助挑选已有音乐起音，不能在静音时单独触发。保留新鲜度/去重/单朵/冷却限制。`energy-rise` 表示当前观测能量高于近期均值，不代表已识别高潮、副歌或准确强拍。

事实：249 项测试与生产构建通过。新增回归覆盖 raw骨架/父变换/CSS偏移投影、手部选择/面部与过期拒绝、准确手部原点与静音拒绝，以及局部峰值/能量抬升。重载实际桌宠后，原本网易云采集已 active，沿用正在播放的《Boom Boom Pow》，未切歌或切换音频模式。约10秒、100次采样中46次有可见粒子，记录4次发射（right/right/left/right，间隔3.14/2.94/2.66秒），截图 `/tmp/komorebi-hand-fireworks-preview.png` 目视确认抬起的手边有烟花；诊断 `/tmp/komorebi-hand-fireworks-live.json`。结束仍沿用用户原播放状态；末次采样时已有粒子清空，这一轮未专门暂停真实歌曲。

假设与待验收：伸展/抬手/速度评分是几何启发式，未理解挥手、指天等动作语义；能量抬升也是信号对比。真实歌曲完整段落下的时机与炫感、不同角色和长期性能仍待观看验收。未增加音乐高潮识别模型，不改变 M1/M2 状态。

## 首版接口与事实

`src/App.vue` 在日常桌宠人物后方挂载 `src/MusicFireworks.vue`，读取现有 audioState。`src/effects/music-fireworks.mjs` 独立负责起音消费、密度预算及 Canvas 绘制，不写入音乐分析、舞蹈选择或身体骨骼。

仅 demo/netease/system 的新鲜 warming/tracking 信号触发；使用 lastOnsetFrame 去重、lastOnsetStrength（兼容 onsetStrength）和 energy，拒绝超过 180ms 的起音及超过 350ms 的观测。起音强度 >0.18、能量 >0.12 才触发。至少间隔 2.2 秒，同屏最多一朵，生命周期最多 1.65 秒；换流也保留冷却预算。无独立定时燃放，不把起音说成强拍或副歌。

两侧交替、金/蓝/紫粉配色，中心短亮、外环扩散、细拖尾与下落闪烁余烬。音乐强弱改变亮度、尺度和 26–38 颗粒子。Canvas 透明且 pointer-events:none，人物和歌词按原顺序绘制在其前方；无贴图、依赖或新增网络请求。复用“音乐舞蹈”开关；系统减少动态效果时关闭。暂停/静音/断流不再发射，已有余烬自然消散。隐藏窗口清空，空闲时不运行动画帧，DPR 上限 2。

## 首版假设与验收维度

假设：2.2 秒最短间隔、最多一朵及两侧留白能够满足“不太密集、纯粹炫”。这是视觉设计选择；是否足够炫、真实歌曲下是否过稀或过密，仍由用户观看验收。当前分析器不能保证检测每个音乐重音，烟花也不弥补该缺口。
