# 继续优化音乐舞蹈主线

问题：stage-09增加了六类动作，但按使用次数和避重复选主题仍偏向轮播；音乐的轻重、起伏和表达层次不够明显。低置信度拍速回退、轻柔舞句被默认待机混入也会影响表现。

新增MusicalDirector：0.35秒短能量/3秒长能量、1.5秒起音密度，响应quiet/flow/drive/rising/settling；0.55秒迟滞抑制抖动。它是本机启发式表达状态，不是音乐风格、鼓点或副歌识别。

内部结构为主题→呼应→对比→回归。稳定音乐允许重复，能量响应变化在下一个内部八拍边界选择适合候选；不是每个起音切动作。呼应变化保留接缝兼容，上身短起音强调有平滑包络，不改变承重脚轨迹。情绪动态系数平滑改变力度。

拍速：短暂丢失置信度保留最近可信BPM约4秒，半/倍拍歧义选择更接近当前拍速的候选，之后仍有限速调整。只对靠近当前拍相位的高置信度起音轻校正，避免把离拍起音强拉成主拍。没有准确下拍/小节识别保证，真实变速的半/倍拍也可能被误判。

优先级：舞句活跃即拥有控制权，低力度不会被hiyori_m05待机混入；静音/失效后正常收势并恢复待机。音乐信号项目保持独立，本轮未修改采集与分析器。

61项测试通过：主题呼应/对比/回归、低/高能量响应与迟滞、持续上升/回落、起音表达不改变脚目标、呼应接缝、短置信度空窗和半/倍拍稳定、轻柔舞句控制权；原有舞句、IK、待机和任务测试保留。

原生复测及诊断见docs/evidence/musical-director-summary.json。数值只证明执行与状态变化，不代替音乐与舞蹈的审美评审。仍未加入鞋底滚动、全身碰撞或成熟舞种动作数据。
