# VRM全身角色对照

用户选择 Jessair 的免费 Cute Model，并自行下载提供VRM。文件为VRM0.x，含独立肩、肘、手、髋、膝、脚踝、脚趾和手指。仅本机导入，元信息标注 Redistribution_Prohibited，不进入仓库、app或源码包。

模型加载使用 Three.js 和 @pixiv/three-vrm。主进程固定读取userData/local-models/Cute_Model.vrm；限制64MB、检查GLB长度与VRM骨骼、拒绝外部URL，资源以IPC传入渲染器并用临时Blob载入。原下载文件保持不变。

动作使用已有本机BVH：以首帧髋部左右和躯干向上轴校准源/目标坐标系，关节方向转换为目标标准骨骼局部四元数。13个方向控制关节加髋部姿态及垂直位置；肩、手、头等继承父节点，未映射手指与独立头部朝向。每帧从rest pose重算，避免累积漂移。人体比例按腿长缩放；未实现脚底接触锁定、身体碰撞与精确扭转。

入口：动作解剖 → VRM · 全身试跳。保持原骨架同一时钟；可慢放逐帧、定位18.17秒举手、调整观察角度。相机完整显示全身。本阶段不替换日常日和桌宠，不把参考舞蹈伪装成音乐实时生成。

验证：41项测试通过，覆盖非法/缺骨骼/外部资源拒绝、手臂与膝部独立变化及无姿态累积；构建、打包并在原生窗口载入实际模型。视觉质量仍需用户评审；几何数值通过不代表舞蹈审美完成。
