## 问题与范围

公开源码需要清楚的产品入口、可验证的贡献路径和分发边界。原本唯一基线提交包含 Live2D 素材及本机截图，直接推送会让这些文件留在公开历史。用户同意从干净快照开始，并要求保留当前全部实现代码；旧历史保留本地分支，原有未提交内容及本机素材已备份，不推送备份分支。

## 验证维度

事实：整理前本机 222 项测试通过；本轮使用合成音乐基准。整理后以干净快照重新安装、测试、构建和原生编译结果为准。原创待机的行为验收是无日和资源也可构造控制器、音乐优先、收势恢复及减少动态效果；整体角色/舞蹈观感并未因此验收。

假设与限制：macOS 私有 MediaRemote 与歌词接口可能变化；本次不发行公证包，不声明已在所有设备可用。完整舞蹈、真实歌曲和长期桌面验收继续按里程碑推进。历史实验所需数据、模型、Python 环境由使用者自行取得许可并配置。

验证结果：干净目录 `npm ci --ignore-scripts` 成功；222 项测试中 221 通过、1 项日和素材专项因资产未分发明确跳过；Vite 构建通过。本机 `build:music`、`build:audio` 通过，脚本语法检查通过。存在前端大 chunk 与可选 Cubism 脚本构建提示，未据此声明性能或 Live2D 页可用。补入当前固定版本的音乐协议声明，避免文档依赖相邻私有项目。
