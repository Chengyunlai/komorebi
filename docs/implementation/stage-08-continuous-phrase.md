# 从动作展示到连续舞句

问题：五个片段每次都由待机开始并回到待机，几乎每个关键姿态都缓停；只按起音挑动作，没有贯穿的运动相位、承重关系与句法，因此仍像依次展示动作。

本版先收敛成共享步法的A/B两段原创八拍舞句。周期Hermite曲线连接重心状态，节点保留速度；胸腰和双臂错峰跟随。脚步按承重/摆动区间运行，五次平滑水平轨迹与零端点速度抬脚弧线，只在摆动区间移动足目标；不强迫全身回待机。

A/B共用脚步和边界状态，B的上身变化在八拍边界位置/一阶导数均为零，内部八拍边界才切换变化。重复是母题的一部分，不再强制避重复。音频调节幅度与连续时钟，tempo缓变，可信起音只轻微校正相位，不重置舞句。低置信度按用户配置拍速估计，诊断标记estimated；内部八拍零点不是检测到的歌曲强拍/小节。背景间隔按有效音频时间前进，静音/失效冻结相位并收势。

支撑脚不因音量变化而缩放水平目标；入场与停止有独立足目标过渡。角色实际左右轴决定足目标方向，骨盆世界位移转父坐标，修正VRM0左右移动相反风险。继续使用解析IK与可达范围修正，未做脚趾滚动、鞋底接触、动量动力学或完整碰撞。

历史vrm-clips.mjs保留作stage-07研究对照，日常路径不再调度五个独立归零片段。无音频显式预览同样播放连续舞句，不代表音频分析成功。

测试：51项通过。新测试验证A/B和循环接缝的位置/速度兼容、八拍边界非待机、单支撑要求、承重期间足目标固定、90/120BPM相位、密集起音不重置、能量变化不拖动落脚、静音冻结与收势。界面重新激活时不再让桌宠抢走可见管理/音乐/研究窗口的焦点。

接缝数值与IK误差不代表舞蹈已经自然。当前目标是先得到可连续观察的简单舞句，下一步由实际观感评审动作质感和连接，而非继续增加动作数量。

原生实测：原创PCM播放和分析闭环成功，观察到交替落脚和连续上身；诊断记录跨八拍时相位递增、无强制待机，见docs/evidence/vrm-phrase-summary.json。低置信度时标记estimated，不能声称准确跟随小节。
