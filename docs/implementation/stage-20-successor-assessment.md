# Stage20：后继兼容评估与接触证据

## 1 本轮做什么

接续E3/E4：脚部运动学证据区分低位稳定、低位移动和抬起，标明estimated而非人工接触真值；显式时间区间标注有独立来源。候选在水平对齐后比较姿态、有向角速度、髋部世界速度及高度差，输出eligible/review/rejected及原因，不以标量速度相近替代运动方向一致。

研究页允许检索和手动预览候选；缺少可信接触标注时不得宣称可自动执行。example `examples/stage-20-successor-assessment/user_code/main.mjs`。断点：脚证据knowledge、速度向量、数值阈值、拒绝原因和候选排序。验收：相反同速旋转可区分、未知接触仅review、标注冲突拒绝、缺失脚数据降级、真实源候选聚合和实际预览。

## 3 资源和调整

## 4 进一步评估

边界兼容不证明整个过渡无穿模/脚滑，也不证明音乐/舞蹈语义适合。先建立可解释拒绝和研究预览，再补标注、完整窗口检查与音乐条件。

### 已执行数值验证

`npm test`133/133通过，新增接触估计/区间标注和后继评估测试。审查中特别修正了两个坐标问题：姿态差使用对齐后的解剖骨世界旋转，避免辅助根与髋局部补偿产生假差；角速度差也按FK世界向量比较，避免辅助场景根带来的整身旋转被忽略。相反同速旋转及场景根独立旋转均有回归测试。

本机研究源从10.5秒出段检索101个备选（9秒后、0.5秒间隔、排除紧邻原动作、入段足够2.5秒）：当前实验阈值下0 eligible、1 review（48秒）、100 rejected。没有放宽阈值制造可用候选。原12.6秒入段的姿态RMS差1.6565rad、解剖骨世界角速度RMS差11.8939rad/s，超过当前0.65rad/4rad/s实验阈值；髋速度差1.3499m/s，高度差0.01665m。

完整0.5秒窗口另以120Hz采样诊断，48秒候选的源髋峰值水平速度约1.0325m/s，原12.6秒方案3.3984m/s。该数字仅描述这两个生成窗口，不能当人体可执行性标准。证据`docs/evidence/successor-source.json`和`successor-window.json`均为聚合，无原始姿态导出。

接触confidence数值仅是当前启发式占位，不是校准概率；决策依赖knowledge与来源，不将估计当可信硬接触。人工/外部区间标注也需要对应来源真实性，标签不等于测力证明。当前真实源没有提供此类标注，全部保留待复核。
