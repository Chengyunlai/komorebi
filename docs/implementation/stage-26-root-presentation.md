## 进一步评估与下一步：以舞蹈表现为主验收

用户指出距离期望的舞蹈仍远。当前核心不足是三个约两拍片段、基于拍速与能量的短片选段，缺乏完整舞句、重心准备与收势、音乐段落和动作组织之间的语义。根/IK指标属于底层正确性，不构成舞蹈自然性证据。下一轮优先让同一VRM完整播放连续源舞段，建立视觉基准：若完整舞段也差则定位绑定/重定向；若完整舞段好而短片调度差则定位切段/编排。再用有明确拍点的完整舞句做保留结构的音乐同步。暂不继续无边界微调局部平滑参数。
