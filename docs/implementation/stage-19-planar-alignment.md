# Stage19：水平轨迹与朝向对齐

## 1 本轮做什么

依据stage18的1.48米源髋部间隔：用交接开始的源髋部XZ和左右髋方向计算一次固定水平刚体变换，贯穿整个入段（包括过渡后）。Y不平移，保持原动作的高度差，不以空间对齐冒充足接触修复。

研究窗口提供未对齐/水平对齐对照、固定/跟随镜头及倾斜地面视角。example路径`examples/stage-19-planar-alignment/user_code/main.mjs`；断点：髋朝向基向量、yaw/translation、对齐前后XZ误差、过渡结束后的同一变换。测试：辅助场景根、纯髋根、高度保留、骨段几何不变、无突跳、退化朝向拒绝；原生VRM固定机位连续对照。

## 2 结果与验证

实施后按实际证据补充，不以消除起点位移宣称舞蹈自然。

## 3 资源和调整

- `npm test`123/123通过，包含辅助场景根/纯髋根、骨段几何和高度保持、输入不变、速度坐标及固定变换连续性；`npm run build`通过（已有Cubism/chunk提示）。

- 原水平间隔1.480270m，经实际应用和FK重建后约1.72e-16m；保持源高度差-0.016651m。过渡末姿态与随后同变换入段的矩阵最大分量差3.38e-14，不发生空间重置。
- 0.5秒过渡以120Hz采样：源髋峰值水平速度未对齐约5.68m/s，对齐约3.40m/s。量纲基于显式0.01米/源单位研究假设；这是当前两窗口的诊断，不能外推所有素材或视为人体可执行门槛。
- 聚合证据`docs/evidence/planar-source.json`不包含原始姿态。固定Y-up假设和左右大腿根朝向方法已附来源；缺失或退化朝向直接拒绝。

对齐消除了场景起点差，仍保留显著运动；下一步应比较姿态、有向速度及接触兼容性，允许拒绝不合适后继，而不是再次用更强平滑掩盖差异。未自动替换日常音乐播放器。
