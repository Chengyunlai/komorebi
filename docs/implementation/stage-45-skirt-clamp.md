# Stage45 裙摆稳定与腿部动作限幅

## 本次做什么

用户反馈："动作大了会把裙子带起来，不喜欢"。

1. **定位**：该 VRM 含 **40+ 裙摆弹簧骨**（`J_Sec_*_Skirt*` + `J_Sec_*_CoatSkirt*` 两层，前后侧），且裙子网格部分绑定大腿骨骼 → 大幅抬腿时裙摆被惯性/蒙皮带飞。
2. **修复**：
   - **裙摆弹簧加固**（`tameSkirtSprings`）：stiffness×4、dragForce×2.2、gravityPower×0.25、hitRadius 调整 → 裙摆更硬、更快停下、少下垂；
   - **腿部动作限幅**：每帧对大腿局部旋转限幅 1.0 rad（约 57°）、膝盖 1.9 rad（约 109°），防止极端抬腿把裙子带飞。
3. 验证：连续 10 帧截图，抬腿动作时裙子仅有轻微摆动，不再掀开。

## 结果、验证与结论

- 裙摆加固 + 腿部限幅后，裙子保持自然下垂状态（大幅动作下轻微摆动可接受）。
- 222 测试通过。
- 代价：腿部动作幅度受限于限幅（约 57° 抬腿），但仍保留 23 支舞的丰富变化。

## 资源和调整

- `Character.vue`：`tameSkirtSprings()`（VRM ready 后调用）、tick 中腿部旋转限幅。

## 进一步评估与下一步

- 若用户希望裙子更"贴身"：可进一步降低 gravityPower 或直接固定裙摆骨（会牺牲飘逸感）。
- 若希望更大腿部动作：需修改 VRM 蒙皮（裙摆权重从腿骨移开），工作量大。
