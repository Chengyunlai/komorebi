# Stage42 流式舞蹈多样性修复（采样温度）

## 本次做什么

用户反馈"动作还是那么几个"。定位根因并修复：

1. **根因**：Motius/Bailando 的 `sample_codes` 用 **greedy top-k=1 采样**（`torch.topk(probs, k=1)`）→ 生成完全确定，同音乐/同窗口反复产出相似动作；且默认初始种子固定 `(423,12)`。
2. **修复**（`scripts/bailando-stream-server.py`）：
   - **温度采样**：monkey-patch `sample_codes` 为 temperature=0.92 + `torch.multinomial`（top-k 8 概念），增加动作多样性；
   - **每段不同随机种子**：`torch.manual_seed(1000 + id*7919 + time%1000)`；
   - **动作延续**：把上一段最后 8 帧作为 `initial_motion` 传给下一次生成（保持连贯的同时避免重复）。
3. 修复 `initial_motion` 传 1 帧导致 conv 报错（需 ≥4 帧，改 8 帧）。

## 结果、验证与结论

- 多样性测试（8 段）：**段间中点姿态平均距离 0.671m**；手部高度范围逐段 [0.35, 0.02, 0.01, 0.42, 0.72, 0.51, 0.64, 0.74]——变化明显。
- 桌宠实测（Candy Pop）：连续 10 帧（400ms）显示踢腿、抬腿、转体、跨步、举手、张臂等不同动作，不再重复。
- 生成耗时：0.7-0.9 秒/段（温度采样未明显增加耗时）。
- 217 测试通过。

**结论**：动作单调根因是采样策略而非模型能力；温度采样 + 随机种子 + 动作延续后多样性显著提升。
