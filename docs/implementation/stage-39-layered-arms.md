# Stage39 Freestyle 分层手臂动作

## 本次做什么

用户再次反馈"还是几个动作来回切换"。根因分析：所有主题共享**同一套手臂基础公式**（`samplePhrase` 的 sin 曲线），主题差异只在窗口内小叠加——所以无论主题怎么换，手臂看起来是同一套动作。

改进：把**手臂从主题中解耦**，变成独立的分层动作系统：
1. **手臂动作库**（`vrm-phrases.mjs` 的 `ARM_MOVES`，8 种）：摆臂、挥手、双手举起、指、抱胸、张开、交替摆、弹手。每个动作是明确的手臂目标形状（reach/front/fold/elbow）+ 内部摆动。
2. **独立时钟**：手臂每 **2 拍**换一次动作（脚步/躯干仍是 8 拍主题）——两层不同频率叠加，组合空间大幅增加，不再是"整段动作切换"。
3. **手臂过渡**：换动作后 0.45 拍内从上一形状平滑混合。
4. 主题的 `samplePhrase` 手臂字段不再主导（被手臂层覆盖），主题仍控制脚步路径、躯干、8 拍变奏。

## 结果、验证与结论

**合成信号探测**（10 秒）：手臂序列 `摆臂 → 弹手 → 交替摆 → 挥手 → 张开 → 摆臂 → 双手举起 → 抱胸 → 指 → 弹手`（10 次变化，覆盖 8 种动作中的 8 种）。

**27 秒渲染抽检**：8 种手臂动作全部出现，画面连贯、无穿模。

**测试**：214 项全部通过（原有 vrm-dance/phrases 测试均未被破坏）。

**结论**：freestyle 从"几个整句切换"变成"脚步主题 + 手臂动作两层独立变化"，多样性显著提升。

- 若还不够：可增加手臂动作数量、降低手臂换动作频率（2 拍→4 拍）或加入"随重音强调"。
- 头部/躯干也可进一步分层（当前仍由主题的 8 拍公式主导）。
