# 日常桌宠切换VRM

目标：以用户选择的Jessair Cute Model替换透明桌面日和，保留单击气泡、拖动、置顶、歌词、任务与TTS；复用独立音乐信号输入，驱动VRM全身关节。

Character.vue使用Three.js/three-vrm载入本机缓存的完整VRM；背景透明，完整身体取景，待机放松双臂、呼吸、眨眼。骨骼姿态使用标准弧度，VRM0.x对X/Z旋转反向适配。仅pet窗口播放demo音频及TTS，语音RMS驱动aa口型。系统语音仍由系统播放，未增加其音频口型采样。

VRMDanceController沿用因果起音片段与频段/能量强度，增加独立肘部弯曲、抬臂、躯干、重心和膝踝协同。它是初版原创程序动作，未使用CC BY-NC研究BVH或派生曲线。仍无接触IK、碰撞求解、精确扭转、脚步编舞；不能将其描述为成熟全身舞蹈生成。

真实音频过期/静音时收势，不通过播放器时间轴伪造跟拍。无音频显式行为预览沿用原有标记。禁用舞动及系统减少动态效果阻止舞蹈，待机眨眼保留。

管理设置增加本机VRM导入，系统文件选择器+原有骨骼/外部资源校验，保存到userData/local-models/Cute_Model.vrm并重载桌宠。仅管理窗口允许导入。模型不随分发包提供。

验证：43项测试通过；实机确认放松待机、完整人物、脚下歌词、右键音乐入口、单击轻气泡。网易云播放Dont Stop Movin'时，诊断renderer=vrm、motionMode=audio，连续新起音触发，肘和膝值独立变化。原生渲染观察已完成。语音实际服务播放与多屏拖动未在本轮重测，原有调用入口保留。
