# hiyori_m05赋予VRM默认待机

用户指定研究窗口选中的hiyori_m05作为蓝发VRM默认动作。新增src/motion/vrm-idle.mjs，复用motion3曲线解析器，加载已随项目保留的原始曲线；原素材不修改。

头XYZ解释为有界三维俯仰、转向与侧倾，躯干X/Z转向/倾斜分配到髋与脊柱。BodyY只解释为轻微上移，不伪装为俯仰；腿部仍由已有IK约束。双臂从源的-10中立位解释为小幅展开，呼吸分配到胸部，眼睛开合/视线映射到VRM表情与lookAt。源张嘴曲线不映射为说话，aa继续由实际语音音频驱动。

原始8.57秒动作首尾存在细微差异，以0.35秒重叠混合构成约8.22秒平滑循环。音乐所有权由舞句strength决定：待机平滑让位，音乐收势后恢复；无双份呼吸叠加，减少动态效果禁用待机运动。选择动作不新增常驻UI。

55项测试通过：真实m05头/体变化、幅度、循环接缝、脚部约束输出、音乐优先/恢复、减少动态效果。运行诊断在userData/idle-motion-diagnostics.json，来源固定标记hiyori_m05；原生实测待机加载与骨骼数值变化。
