# 连续舞句增加变化

用户认可连续性，但共享步法的A/B变化太少。本版保留内部持续时钟与八拍接缝，扩展六类原创主题：侧踏摆臂、宽步绕臂、前点胸腰、提膝对摆、斜踏伸展、后点低律动。

主题的足轨迹分别改变侧向幅度、前后/斜向方向、抬脚高度，身体有不同下沉、胸腰转动、侧倾与手臂配合。不是将同一个手臂动作换名称。全部遵守相同承重时段，接缝足位置/速度兼容；上身新增项以零边界值和零边界导数的窗函数进入。

选择在内部八拍边界执行，使用1.2秒平滑的频段/能量、行为风格、近期主题及使用次数评分，避免稳定音乐长期停在一个主题。保持共同基础母题，不在每次起音换动作，不把内部八拍称为准确检测的歌曲小节。

53项测试通过：全部36种主题连接、踩住时足目标固定、每主题至少一支撑脚、不同主题运动特征明显不同、稳定输入下逐渐覆盖六类且不在句中切换。构建和本机打包通过。实际表现仍需视觉评审；无人体碰撞、精确鞋底接触和真实舞种教学级动作保证。

原生实测：网易云进程音频持续输入，已观察到不同主题切换；最近窗口记录见docs/evidence/vrm-theme-summary.json。脚步和上身在透明桌宠中实际渲染，保留原有歌词与交互。
