# 角色获取与命令安装 · 2026-11-04

## 问题与交付

公开快照只说“自行导入角色”，首次安装者和安装 AI 缺少下载入口及命令。演示使用 Jessair Cute Model；角色禁止再分发，不能通过把现有本机文件加入仓库来解决。

新增 `npm run setup:avatar`：无参数输出作者页面、登录下载步骤、许可摘要和命令；传入本机 `.vrm` 后复用 `electron/vrm-model.cjs` 校验，写入应用已使用的 `local-models/Cute_Model.vrm`。默认使用 macOS Komorebi 数据目录，支持 `KOMOREBI_DATA_DIR` 和优先级更高的 `--data-dir`。临时文件完成后原子发布，默认拒绝覆盖，`--replace` 才替换；无效文件不改写旧角色。命令不访问网络、不改设置数据库，安装后需重启应用。

中英文 README、AGENTS.md、使用与文档索引同步，新增[完整安装说明](../avatar-setup.md)。安装 AI 应提示独立下载；无角色时报告“程序已安装，角色待下载”。其他有许可的 VRM 可使用同一入口。

## 事实、假设与验收

- **事实 · 获取边界：** 2026-11-04 打开[作者页面](https://booth.pm/ja/items/7100270)，Cute_Model.vrm 标价免费，条款允许个人/商业用途但禁止再分发、转卖、NFT 和 AI 训练；点击下载重定向 BOOTH 登录页。因此此入口是“官方下载指引 + 本机安装”，没有提供无人值守下载。
- **事实 · 文件安装：** 两项新增测试覆盖临时应用目录安装、带空格路径、环境目录/显式目录、保留现有文件、显式替换、无效文件拒绝及临时文件清理；无参数指引和无效参数退出码也通过。真实本机 VRM 在独立临时目录安装后与原文件逐字节哈希一致，临时目录已清理，现有应用角色未修改。
- **事实 · 工程验证：** `npm run verify` 256 项测试全部通过，Vite 构建通过；保留既有可选 Cubism 脚本及 chunk 大小构建提示。分发检查另核验暂存源码、文档链接及素材边界。
- **假设与限制：** 作者页面、下载流程和条款可能变化，以作者当前说明为准。没有代用户登录或重新下载，没有在新设备上验收桌面显示；VRM 结构校验不保证每个模型的外观与骨骼表现。日常渲染和音乐决策未修改，M3/M4 整体验收不因此通过。

下一步可由首次安装者按指引完成 BOOTH 下载、命令安装及实际角色显示验收。视频、角色、歌曲仍只在本机。
