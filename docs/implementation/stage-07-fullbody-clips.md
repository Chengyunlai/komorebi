# 从抬手到全身片段

问题：上一版把同一组上身标量映射到手臂和膝部，虽然有信号关联，仍表现为反复抬手、轻晃，缺少完整动作意图。

本版将日常VRM音频路径改为五类原创关键姿态片段：step-touch、cross-open、diagonal-reach、knee-drive、body-drop。肩臂、肘腕、胸腰、重心与足目标有各自曲线；用smoothstep分阶段缓动和短时平滑，左右镜像。动作不来自本机CC BY-NC研究BVH。

因果调度：有效新起音才选择新片段；已有主片段先完成，不被密集起音重置。能量决定幅度，频段影响候选，近期片段避重，可信tempo仅用于时长。短鼓间隙不切断动作，明确silent/lost、过期、stop、禁用时清除主片段并收势。没有可靠小节/副歌检测，也没有预知下一拍。

落脚：标准骨骼方向适配后，以本机模型初始踝位置作为支撑目标；摆动脚使用片段目标。解析双骨腿IK保持目标，必要时小幅降低骨盆，避免侧踏时腿长不足。踝朝向保持初始世界朝向，未做鞋底接触、脚趾滚动、全身碰撞与完整平衡求解。不能将踝目标误差等同于鞋底完全贴地。

测试覆盖：动作关键阶段和镜像、密集起音不重启、肘膝及足目标变化、静音/断流/禁用、短鼓间隙连续、支撑腿在骨盆移动时的解析误差、侧踏双腿可达。

实机已观察真实网易云输入出现全部五类动作，膝部角度超过0.9弧度。原创PCM复测明确静音段收势，足目标修正误差见docs/evidence/vrm-clips-summary.json。数值仅验证执行链，不代表审美完成；穿模和手臂扭转仍有改进空间。

最终47项测试通过，构建、应用打包及签名验证完成。
