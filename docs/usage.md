# 使用与配置

从 [README](../README.md) 完成源码构建后，以托盘“配置与管理”为入口导入 VRM、选择项目、设置任务后端。没有角色素材时角色区域会提示导入，托盘仍可打开管理窗口。

演示角色可从 [Jessair 的 BOOTH 页面](https://booth.pm/ja/items/7100270)免费取得，需登录并下载 `Cute_Model.vrm`；角色禁止再分发，因此未附带。下载后退出应用，运行 `npm run setup:avatar -- "$HOME/Downloads/Cute_Model.vrm"` 并重新启动，或使用偏好设置导入。其他授权 VRM 也可使用。完整步骤及 AI 安装约定见[角色安装](avatar-setup.md)。

## 交互

单击角色展开气泡，按住拖动，右键打开菜单。Enter 发送、Shift+Enter 换行、Esc 收起。点击气泡外默认自动收起，草稿保留，任务继续；可在偏好设置关闭。Option+Space 带入剪贴板，Option+Shift+S 框选截图，Option+Shift+H 显示/隐藏伙伴。快捷键冲突与截图权限依设备设置处理。

任务只做只读分析。每次提交为独立任务，注入与当前项目相关且经确认的结论，不共享完整历史。结果不会自动成为事实，“留下结论”需人工核对。任务执行经独立 Codex CLI，不继承 Codex 桌面应用专用模型别名和 MCP 配置。

## 模型与语音

默认任务模式使用本机 Codex CLI 登录。火山引擎在“偏好设置 → 对话与任务模型”配置 Base URL、模型与自己的 Key；地址和模型以服务商当前账户权限为准。不同端点可能采用不同计费方式，保存后不会自动回退到其他提供方。

也可通过启动环境导入 `MOZI_LLM_PROVIDER`、`HARNESS_LLM_BASE_URL`、`HARNESS_LLM_MODEL`、`HARNESS_LLM_API_KEY`。这只是变量适配，尚未接入 mozi-harness SDK；密钥不写入命令行或源码。语音单独使用系统朗读或 MiMo Key，默认关闭；专注模式关闭完成通知与自动播报。

## 音乐与声音

继续在网易云客户端播放，从“音乐 · 网易云”查看当前曲目、歌词和播放控制；可选择真实音频跟拍或系统声音跟拍。首次采集需 macOS 授权。原创节奏试跳使用项目自己的合成 PCM，不需要歌曲文件。歌词歧义或不可用时显示曲名；没有可信节奏时不声称准确踩拍。

开启音乐舞蹈时，烟花会在较突出的音乐起音或能量抬升时从角色手边绽放，只在明确抬手或伸展时触发；至少间隔2.2秒、同屏最多一朵，安静段更稀疏。没有合适手部位置时跳过；暂停后余烬自然散去。当前按声音变化挑选时机，尚不能识别歌曲高潮或副歌。关闭音乐舞蹈或开启系统“减少动态效果”会关闭烟花。

真实音频仅本机分析，不上传。Bailando 研究路径可能短暂写入临时 WAV，需自行安装 Python 环境、框架与权重；默认不下载。全局采集可能包含应用自身播报，当前没有完整回声隔离。MediaRemote 是 macOS 私有 API，系统升级或网易云接口变化可能影响功能。

## 本机数据与网络边界

设置、任务与结论存于 `~/Library/Application Support/Komorebi/komorebi.sqlite`；截图存于同目录 captures，用户角色与动作素材也留在应用数据目录。Key 由 Electron safeStorage 加密保存。备份、共享日志或截图前自行移除个人内容。

用户提交时，任务文本、所选截图与相关结论会交给所选后端；匹配歌词会将当前曲目信息发送至网易云；MiMo TTS 将所朗读文字发送至 MiMo。无常开麦、ASR、跨设备同步或自动消息发送。

## 可选研究素材

源码不提供 VRM、BVH、Live2D 模型或 Cubism Core。日常 VRM 使用原创待机后备；若本机已有日和 m05，则沿用其许可单独解释播放。历史 Live2D 研究页需要用户自行取得相关授权资源，放入 `public/vendor/` 后重新构建；缺少素材时这些页不可用，集成测试会明确跳过资产专项用例。

研究顺序与能力边界见 [examples](../examples/README.md) 和 [第三方说明](../THIRD-PARTY-NOTICES.md)。
