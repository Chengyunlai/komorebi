# 木漏日桌宠首版

已授权目标：macOS 优先，一个二次元角色、复制或框选交办、真实任务状态、结果回收、项目结论保存与查询。

实际复用：AIRI 的 Live2D 口型模块，AIRI 使用的 Hiyori 示例模型与 Pixi 渲染技术。磁盘约 4 GB 可用，暂不安装 AIRI 全部 workspace。独立薄壳只承担桌面入口，执行复用本机 Codex CLI，SQLite 保存任务与知识。

主要路径：复制或框选 → 检查输入和目标项目 → 提交解释任务 → 可取消的执行 → 结果可复制 → 用户确认保存结论 → 按项目检索、修改、导出。

默认不发送剪贴板。快捷键只装入草稿，提交按钮才发送。首版任务使用只读沙箱；不把桌宠 UI 中的确认当成对所有外部写操作的授权。角色只在用户点击、任务失败或完成时反馈。

验收：真实后端返回、取消任务后不再变成功、项目知识隔离、保存后重启可查、角色渲染、剪贴板与截图进入草稿、窗口可隐藏/恢复。MiMo 需要用户提供 Key，系统语音提供本地备用。


## 0.2 方向修正

用户明确日常只需要桌宠。启动只显示透明角色窗口，大窗口降为配置与管理。角色点击、托盘和剪贴板快捷键均进入旁边的小对话；小对话覆盖输入、附件、只读任务状态、结果、取消与结论确认。Esc 收起后草稿保留。移除大窗口交办首页与重复的角色展示。


人物交互修正：平时只显示角色；左键按住移动，单击对话，右键菜单。删除底部常驻功能栏，拖动位置持久化。


轻量任务气泡：角色单击默认展开约320×140输入气泡，隐藏项目栏和旧结果。发送任务后展开回复，历史回复由用户点开；项目、框选、配置放在“＋”下。气泡贴在角色身边，按当前内容调整高度，上限440。


## 任务气泡视觉重设计

依据用户截图与 help-me-design 流程：去掉重复标题栏、文字历史入口和输入框内部焦点线。采用暖白单层气泡、圆角、轻描边、朝向人物的尾角。底部用更多/剪贴板/历史小图标，发送按钮区分空白与有输入状态；键盘焦点以气泡边缘和按钮焦点环表达。输入按内容增长，回复按长度展开，长回复滚动，复制与保存操作位于滚动区外。展开操作保留项目与框选，Esc先收起操作栏、再收起气泡。

构建前参考实现保留于工作目录 work/bubble-before；设计预览 docs/bubble-preview.png 使用未发送的示例输入，非真实任务回执。没有使用在线生成素材。


输入规则：Enter发送，Shift+Enter换行；中文输入法组词确认不触发发送。气泡左侧快捷图标暂时移除，等待用户明确功能定位。项目、剪贴板、框选仍可从右键菜单与管理界面使用。


气泡默认失焦收起：点击其他窗口或桌面自动隐藏气泡，保留未发送草稿，不影响后台任务。在偏好设置的“桌面气泡”中提供“点击气泡外自动收起”开关，默认开启并持久化；关闭后仍可Esc或手动关闭。


## 自有火山引擎 LLM

宿主仍采用 Electron/Vue/Live2D，TaskRunner 通过独立 Codex CLI JSONL 执行只读任务；新增火山 Responses 提供方配置覆盖，复用执行器的工具调用和取消语义。SQLite 保存任务、项目结论和加密后的 Key；密钥不写源码或安装包。支持所给 HARNESS_LLM_* 与 MOZI_LLM_PROVIDER 启动环境，但不引入 mozi-harness SDK。模型与端点保持用户指定，不自动降级或切换计费地址。配置可从设置修改，任务执行时不允许切换提供方。


## 音乐陪伴首版

网易云客户端负责播放。右键或托盘的“音乐 · 网易云”打开330×290轻量小窗；平时只保留完整人物和脚下浅紫、奶油、浅绿渐变文字。复用 mediaremote-adapter 隔离进程读取系统播放状态，自动过滤网易云 bundle；按曲名、歌手、时长查询并校验歌词版本，歧义时回退曲名。曲目和歌词不进 LLM、任务或项目记忆。

人物通过 Live2D 头、身体、手臂参数及轻微纵向移动实现律动，按播放时间轴同步，可调60–160 BPM，默认100，未采集或分析音频节拍。暂停平滑归零，独立于专注模式，可单独关闭，遵循系统减少动态效果。歌词按LRC时间轴跟随进度，支持暂停和拖动进度后的回退；当前不提供逐字卡拉OK或译文。

小窗提供网易云播放控制并即时复核来源，避免发给其他播放器；不下载音乐，不读取登录态，不改变音乐会员权限。预览使用原创示例歌词且明确无音频，实际播放优先。
